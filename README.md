# Visuals Client (Fabric, Minecraft 1.21.11)

Build:  ./gradlew build   ->  build/libs/visuals-client-1.0.0.jar
Install: put the jar (NOT the -sources jar) in your Modrinth profile's mods folder.
Requires Fabric Loader 0.18+, Fabric API for 1.21.11, Java 21.

Open the menu with Right Shift (rebind in Controls).
No gradle wrapper is included: run `gradle wrapper --gradle-version 9.2.0` once,
or copy gradlew/gradle/ from the official template at fabricmc.net/develop/template.
